# The Anxious Printer

One line about office life: our printer only ever jams when a deadline is near. The joke's turn is giving the machine the most human office ailment of all — performance anxiety — so the thing everyone blames for ruining their day turns out to be just as stressed about the deadline as they are. It rings true because every office has that one printer that works fine all week and falls apart the moment something actually matters.

## How to run

```sh
python3 main.py
```

This writes the single joke line to `/output/entry.txt`, after checking it is exactly one line, non-blank, valid UTF-8, and under 200 characters.
